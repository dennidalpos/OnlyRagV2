## Scope and method

The audit started on **2026-10-05**; final tracker/documentation review completed on **2026-10-06** (Europe/Rome). Verification and advisory dates below identify when those checks were actually performed.

Audited checkout: `master`, source commit `ceaad81`, initially clean. Host: Windows/PowerShell, Node **24.20.0**, npm **11.19.0**, Python **3.13.15**, Vitest **4.1.11**. No runtime source, dependency, generated contract, personal setting/store, model, installer or retained live campaign was changed. No commit/push.

The repository-wide inventory covered **928 tracked files**. Import/lint/format/dead-code checks were complemented by source, caller and verification-path review across Renderer hooks/views, Electron Main/preload/IPC, agent orchestration/tools, persistent stores, Sidecar ingestion/OCR/normalization/translation/retrieval/history, packaging/setup/cleanup, CI, documentation and local skill references. Large files and marker searches guided review; a large module or the word `legacy` alone was not treated as a defect. This is a repository-wide audit with targeted behavioral probes, not execution of every possible application path.

New tests were run only after concrete problems emerged. Temporary Vitest/pytest probes used synthetic files, declared adapters and a real isolated LanceDB table; no Ollama calls, desktop crash, personal migration or cleanup campaign was executed. Probes asserted the intended invariant and failed on the existing behavior. Their failures below are confirmed **pre-existing product defects**, not regressions from this documentation-only change. Temporary harnesses were removed after recording the results and reproduction steps here.

Priority: **P1** protects data/privacy or restores a broken core flow; **P2** completes reliability, recovery or distribution verification; **P3** corrects lower-impact current documentation. Advisory severity and application exploitability are separate facts. Deferred/exhausted model work retains its authorization limits.
