## Pulizia e riallineamento documentale — 22 ottobre 2026

Dopo il [lotto del tracker del 22 ottobre](./verification-tracker-lot-2026-10-22.md), sono stati rimossi dal checkout i 9 output/cache rigenerabili (`coverage/`, `dist/`, `dist-electron/`, `node_modules/.cache/`, `node_modules/.vite/` e 4 directory `sidecar/**/__pycache__`) tramite [`clean_repo.ps1`](../scripts/clean_repo.ps1) previo backup verificato SHA-256 di 98 file in `%TEMP%/onlyrag-p10-repo-cleanup-backup-20261022`, la directory vuota orfana `.github/workflows` e 11 simboli/import di dead code privi di chiamanti in 11 file sorgente/test. [`cleanup_policy.ps1`](../scripts/cleanup_policy.ps1) include ora le directory `__pycache__` esplicite del repository (32 casi isolati in [`test_cleanup_policy.ps1`](../scripts/test_cleanup_policy.ps1)). Le guide di ambito ([`operations.md`](./operations.md), [`ingestion.md`](./ingestion.md), [`guida-utente.md`](./guida-utente.md), [`libraries.md`](./libraries.md), [`README.md`](./README.md), [`history.md`](./history.md)) sono riallineate ai fix del 22 ottobre e ai residui aperti; [`guida-utente.md`](./guida-utente.md) affianca ora 26 diagrammi `mermaid` (`flowchart TD`, sezioni `00`–`25`, verificati automaticamente da [`validate_documentation.mjs`](../scripts/validate_documentation.mjs)) ai 26 SVG offline locali e ai relativi percorsi testuali.

Controlli eseguiti in questa sessione: `npm run docs:check` (121 Markdown e 26 diagrammi Mermaid), `npm run format:check`, `npm run typecheck`, `npm run quality:static` (891 file, 107 handler IPC), `npm run audit:deadcode` (`knip` normale e `--production`), `npm run audit:cycles` (`dpdm` 475 file, zero cicli), `npm run assets:check`, 209 test Vitest mirati su 9 file modificati (inclusi 8 test in [`validate_documentation.test.mts`](../scripts/validate_documentation.test.mts)), 94 test `pytest` mirati su 4 file e gate `scripts/check_python_critical.py` (15 casi su 8 controlli obbligatori senza skip, eseguiti con overlay `pytest==9.1.1` isolato in `%TEMP%` e `PYTHONDONTWRITEBYTECODE=1`), 32 casi `test_cleanup_policy.ps1`, 17 casi `test_log_cleanup.ps1`, parità AST/OpenAPI su 15 route REST, validità XML dei 26 SVG in `docs/assets/flussi-utente/` e integrità SHA-256 dei 66 file di `userdata_dev`.

Limiti della verifica del 22 ottobre: il `.venv` del checkout non conteneva `pytest` e l'ambiente Python esterno del 21 ottobre non era più utilizzabile per collegamenti a directory TEMP svuotate; la suite Vitest completa aveva il fallimento pnpm e `/health` descriveva il provider disponibile anche dopo fallback CPU. I due difetti sono corretti nel [lotto del 24 ottobre](./verification-tracker-lot-2026-10-24.md); pytest resta esterno al `.venv`, senza modificarlo. Le ricevute storiche non comprendono inferenze con modelli reali, nuovi build/installer, letture remote di advisory/Dependabot o migrazioni personali. Per la consegna di quella sessione vedere [`session-handoff-2026-10-22.md`](./session-handoff-2026-10-22.md); il [riesame del 21 ottobre](./documentation-audit-2026-10-21.md) e il relativo [commit di cambio sessione](./session-handoff-documentation-2026-10-21.md) conservano i propri esiti datati.
