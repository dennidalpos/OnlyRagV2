## Session deletion staging and cleanup recovery - 2026-10-15

An interrupted `.preparing-*` directory is retained. On restart, Main publishes it only after the complete manifest and every retained asset pass readback; incomplete preparations appear in the recovery banner with an export action. They cannot be retried or restored because deletion has not started. They no longer block unrelated session writes. A pending final operation still fences its session until Retry or Restore completes. The source integration test reopens the journal after state and checkpoint removal and verifies exact bytes after Restore. Earlier owned-process interruption receipts for the staging and cleanup boundaries are recorded in [the dated verification history](./verification-history-2026-10-13.md#main-session-deletion-recovery--2026-10-12). Current source checks passed: 22 focused tests, 2703 full tests, static quality, documentation validation, TypeScript build and Vite build. Node documents that `copyFile` is not guaranteed atomic, so byte readback precedes publication and follows export ([Node.js 24 filesystem API](https://nodejs.org/docs/latest-v24.x/api/fs.html#fspromisescopyfilesrc-dest-mode)). This qualification does not assert power-loss durability or a new packaged-process restart probe.

## Coding history close and interruption probe - 2026-10-15

`node scripts/e2e/codingHistoryDurability.mjs` passed in an isolated Electron user-data root: exact acknowledged action logs survived normal close, then another acknowledged update survived forced Main termination. A previous hook regression probe proved that a refused save was lost on unmount/reopen. After the approved [Main-owned recovery journal](./architecture/coding-history-recovery-proposal.md) was added, the current probe staged a new revision, made canonical history unreadable to force a refused save, closed Main, restored the original canonical bytes, and restarted Electron. The retained revision appeared over IPC; Export produced a separately read back JSON copy; Retry restored the exact third action log to canonical history, and the journal then emptied. Focused tests cover latest-revision acknowledgement, corrupt-record refusal and changed-canonical conflict. This qualifies the source Electron process and isolated profile, not an installed package, Windows shutdown event, crash before staging acknowledgement or power-loss durability. Electron documents that `before-quit` is not emitted on Windows system shutdown/restart or logout ([Electron app events](https://www.electronjs.org/docs/latest/api/app#event-before-quit)); React effect cleanup cannot serve as a durability acknowledgement ([React useEffect](https://react.dev/reference/react/useEffect)).

Checks: `npm run test` (313 files, 2708 tests), `npm run build`, `npm run quality:static`, `npm run docs:check`, focused close-bridge regression and the rebuilt Electron probe all passed. The final focused test was added after the full suite and passed separately (20/20 hook tests).
